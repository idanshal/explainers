# PostgreSQL

PostgreSQL is an open-source relational database management system. It stores rows in tables, accepts SQL queries, and provides constraints and transactions to preserve data integrity. Applications connect through a driver and authenticate as a database role; deployed instances also need security, monitoring, backups, and an upgrade plan.

For database-model comparisons, see [Choosing a Database](../../../../../content/databases/concepts/database-types.md), or
