# Neo4j

Neo4j is a graph database that stores entities as nodes, connections as directed relationships, and attributes as properties. Cypher queries match and traverse graph patterns. Use a graph model when connected-data queries are central to the workload; identifiers, constraints, security, and backups remain necessary.
